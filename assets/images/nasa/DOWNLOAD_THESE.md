# Optional NASA image files for offline use

These seven official NASA images are referenced by the website. In the current project ZIP, this folder contains this instruction file only; the seven JPEG files are **not bundled locally**. The website attempts to load the official NASA-hosted image when the local file is absent, so an internet connection is required for these images.

To make them available offline, save each image into this folder using exactly the filename shown:

- `as11-40-5927_orig.jpg` ← https://assets.science.nasa.gov/dynamicimage/assets/science/psd/lunar-science/2023/09/as11-40-5927_orig.jpg
- `as15-85-11471_orig.jpg` ← https://assets.science.nasa.gov/dynamicimage/assets/science/psd/lunar-science/2023/09/as15-85-11471_orig.jpg
- `PIA00381.jpg` ← https://photojournal.jpl.nasa.gov/jpeg/PIA00381.jpg
- `PIA00396.jpg` ← https://photojournal.jpl.nasa.gov/jpeg/PIA00396.jpg
- `PIA15384.jpg` ← https://photojournal.jpl.nasa.gov/jpeg/PIA15384.jpg
- `PIA19167.jpg` ← https://photojournal.jpl.nasa.gov/jpeg/PIA19167.jpg
- `PIA21906.jpg` ← https://photojournal.jpl.nasa.gov/jpeg/PIA21906.jpg

The website's source pages and fallback policy are documented in `../IMAGE_CREDITS.md`.
